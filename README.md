# Oppslutning per stemmekrets
Dette programmet tar inn csv-filer av partienes oppslutning ved valg per stemmekrets og plotter.
Programmet baserer seg på filformatet til https://valgresultat.no/

Python-fila main.py leser filene i mappa csv og lagrer figurer i en mappe kalt plots.

Programmet forutsetter at du har matplotlib.pyplot installert.
